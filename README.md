# 📒 Daily Log — จดทุกอย่างในชีวิตประจำวัน

เว็บแอปสำหรับบันทึก **ค่าใช้จ่าย, เมนูอาหาร, การดื่มน้ำ และการออกกำลังกาย** ในชีวิตประจำวัน
พร้อมระบบ **sync ค่าใช้จ่ายกับทุกกิจกรรมอัตโนมัติ** — เขียนด้วย Flask เป็นไฟล์เดียว (`app.py`) ตกแต่งด้วย Tailwind CSS (CDN)

## ✨ ฟีเจอร์

| หน้า | รายละเอียด |
|---|---|
| 🏠 **ภาพรวม** | สรุปรายวัน: ค่าใช้จ่าย, แคลอรี่ที่กิน/เผาผลาญ/สุทธิ, ปริมาณน้ำเทียบเป้าหมาย, เวลาออกกำลังกาย · ปุ่มดื่มน้ำด่วน (+150 ถึง +750 ml) · ค่าใช้จ่ายแยกหมวด · กราฟ 7 วันล่าสุด · เลื่อนดูวันก่อนหน้า/ถัดไป |
| 💸 **ค่าใช้จ่าย** | บันทึกรายจ่ายแยกหมวด (อาหาร, เครื่องดื่ม, เดินทาง, ช้อปปิ้ง ฯลฯ) พร้อมยอดรวม |
| 🍽️ **เมนูอาหาร** | มื้อ (เช้า/กลางวัน/เย็น/ของว่าง), เมนู, แคลอรี่, ค่าใช้จ่าย |
| 💧 **ดื่มน้ำ** | ชนิดเครื่องดื่ม, ปริมาณ (ml), ค่าใช้จ่าย |
| 🏃 **ออกกำลังกาย** | ประเภท, ระยะเวลา (นาที), แคลอรี่ที่เผาผลาญ, ค่าใช้จ่าย |

ทุกหน้า: เพิ่ม / แก้ไข / ลบ / กรองตามวันที่

## 🔗 การ Sync ค่าใช้จ่ายกับกิจกรรม (2 ทาง)

- ใส่ **ค่าใช้จ่าย > 0** ในกิจกรรม → สร้างรายการในหน้า "ค่าใช้จ่าย" ให้อัตโนมัติ ตามหมวดที่ตรงกัน
  (อาหาร → `อาหาร`, ดื่มน้ำ → `เครื่องดื่ม`, ออกกำลังกาย → `ออกกำลังกาย`)
- **แก้ไขกิจกรรม** → รายการค่าใช้จ่ายอัปเดตตาม · **ลบกิจกรรม** → รายการค่าใช้จ่ายที่ผูกไว้ถูกลบด้วย
- **แก้จำนวนเงิน/วันที่ในหน้าค่าใช้จ่าย** → ค่าใช้จ่ายของกิจกรรมอัปเดตกลับ
- **ลบรายการค่าใช้จ่ายที่ผูกไว้** → ค่าใช้จ่ายของกิจกรรมนั้นกลายเป็น 0
- ปุ่ม **🔄 Sync** ในหน้าภาพรวม ใช้ตรวจและซ่อมข้อมูลทั้งหมดให้ตรงกัน

รายการที่ sync แล้วจะมีป้าย 🔗 กำกับ

## 🚀 การติดตั้งและรัน

ต้องมี Python 3.9 ขึ้นไป

```powershell
pip install flask
python app.py
```

> บน Windows ถ้าคำสั่ง `python` ไม่ทำงาน ให้ใช้ `py` แทน เช่น `py -m pip install flask` และ `py app.py`

เปิดเบราว์เซอร์ที่ **http://127.0.0.1:5000**

ฐานข้อมูล SQLite (`daily.db`) จะถูกสร้างอัตโนมัติไว้ข้าง `app.py` ตอนรันครั้งแรก

## ⚙️ ตั้งค่า (Environment Variables)

| ตัวแปร | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `WATER_GOAL_ML` | `2000` | เป้าหมายดื่มน้ำต่อวัน (ml) |
| `DAILY_DB` | `daily.db` (ข้าง app.py) | ตำแหน่งไฟล์ฐานข้อมูล |
| `PORT` | `5000` | พอร์ตของเว็บ |
| `SECRET_KEY` | `dev-secret-change-me` | คีย์สำหรับ session/flash — **ควรเปลี่ยนถ้านำไปใช้งานจริง** |

ตัวอย่าง (PowerShell):

```powershell
$env:WATER_GOAL_ML = "2500"; $env:PORT = "8000"; python app.py
```

## 🗂️ โครงสร้างโปรเจกต์

```
.
├── app.py      # ทุกอย่างอยู่ในไฟล์นี้: routes, database, templates (Jinja + Tailwind)
├── daily.db    # ฐานข้อมูล SQLite (สร้างอัตโนมัติ)

```

### ตารางในฐานข้อมูล

| ตาราง | คอลัมน์หลัก |
|---|---|
| `expenses` | date, time, amount, category, note, **source_type, source_id** (ใช้ผูกกับกิจกรรม) |
| `meals` | date, time, meal_type, menu, calories, cost, note |
| `water` | date, time, drink, ml, cost, note |
| `exercises` | date, time, activity, minutes, calories, cost, note |

### เพิ่มกิจกรรมประเภทใหม่

แก้ dict `ACTIVITIES` ใน `app.py` (กำหนด label, icon, หมวดค่าใช้จ่าย, fields) แล้วเพิ่ม `CREATE TABLE` ใน `init_db()` และบรรทัดแสดงผลใน macro `activity_line` — ฟอร์ม, หน้ารายการ และระบบ sync จะทำงานให้อัตโนมัติ

## ⚠️ หมายเหตุ

- `app.run(debug=True)` เหมาะสำหรับใช้งานบนเครื่องตัวเองเท่านั้น หากจะ deploy ให้ปิด debug และใช้ WSGI server เช่น `waitress` หรือ `gunicorn`
- ไม่มีระบบล็อกอิน — ออกแบบมาสำหรับใช้งานส่วนตัว
- Tailwind CDN ต้องใช้อินเทอร์เน็ตในการโหลดสไตล์
